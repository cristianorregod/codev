## Mi rol

El proyecto fue una iniciativa mía y sigo siendo su responsable directo. En un equipo de dos personas, me encargué de su arquitectura, sus agentes y su API desde el primer MVP hasta las funcionalidades actuales.

- **Arquitectura de agentes**: Diseñé el grafo de estados en LangGraph con un supervisor que planifica, delega en especialistas y revisa sus resultados antes de responder.
- **Agentes especializados**: Desarrollé los agentes de crédito, inmobiliario, datos de cliente y análisis financiero (Brújula), cada uno con sus propias herramientas e instrucciones.
- **API y seguridad**: Construí el servicio en FastAPI con autenticación JWT, propiedad de chats por usuario y respuestas en streaming.
- **Flujo de documentos**: Implementé la carga directa de PDF a Azure Blob Storage, la extracción con IA de reportes crediticios y la generación de reportes en PDF.
- **Datos y entrega**: Configuré la persistencia en PostgreSQL, las migraciones SQL versionadas, la imagen Docker y la documentación técnica.

## Funcionalidades clave del proyecto

- Agente supervisor que arma un plan ordenado de especialistas, revisa cada resultado y decide si continuar o finalizar, con un límite de iteraciones para evitar ciclos.
- Agente de crédito que responde sobre políticas y requisitos mediante recuperación sobre un almacén vectorial de documentos.
- Agente inmobiliario que busca propiedades a través de una API externa de inmuebles con filtros como ciudad, presupuesto y tipo de inmueble.
- Agente de datos de cliente que consulta el backend de la empresa sobre el cliente asociado al chat, pidiendo solo el nivel de detalle que la pregunta requiere.
- Agente Brújula que analiza un reporte de centrales de riesgo cargado, fundamenta su interpretación en un manual de referencia y genera un PDF de análisis financiero estructurado.
- Un nodo de respuesta final que mantiene una única voz consistente en cada respuesta.
- Memoria de conversación por chat en PostgreSQL, endpoints síncronos y en streaming (SSE), y validaciones de identidad que mantienen cada chat ligado a un solo cliente.

## Impacto logrado

Los asesores tienen un único punto de entrada conversacional para resolver preguntas de operaciones y crédito. Además, el asistente analiza los reportes de centrales de riesgo y genera el informe financiero listo para el cliente, lo que duplicó la capacidad de gestión de clientes de los asesores comerciales.

## Tecnologías

| Tecnología          | Uso / Implementación                                                       |
| ------------------- | -------------------------------------------------------------------------- |
| Python              | Lenguaje principal de los agentes, la API y el flujo de documentos.        |
| LangGraph           | Grafo de estados que orquesta el supervisor y los agentes especializados.  |
| LangChain           | Integración de modelos, enlace de herramientas y salidas estructuradas.    |
| OpenAI              | LLM de todos los agentes, recuperación con file search y análisis de PDF.  |
| FastAPI             | API HTTP con autenticación JWT, endpoints de chat y streaming SSE.         |
| PostgreSQL          | Checkpointer de conversaciones, propiedad de chats, documentos y reportes. |
| Azure Blob Storage  | Almacenamiento de los reportes crediticios cargados y los PDF generados.   |
| Jinja2 / WeasyPrint | Plantillas HTML de reportes convertidas a PDF.                             |
| Docker              | Imagen de contenedor con las dependencias nativas para generar PDF.        |
