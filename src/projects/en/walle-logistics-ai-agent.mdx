## My role

As a co-developer in a team, I focused on turning the agent's analysis into real actions. The AI classification and suggestion core was built by teammates; my work covered the execution layer and several modules around it.

- **Action execution layer**: Built the execution of vendor emails, Teams notifications and ERP updates.
- **Authentication and roles**: Implemented user authentication and role-based access.
- **Standard actions and prioritized lists**: Developed the deterministic standard actions per scenario and the prioritized daily worklists.
- **Multilingual notifications**: Built the notification messages in multiple languages.
- **Finance module**: Developed the module for payment supports.
- **International transit**: Built most of the international transit workflow: pickups, freight quotes, customs follow-up and last mile.

## Key project features

- Daily orchestrated sync that pulls pending vendor emails from the ERP and cleans them.
- LLM-generated structured summary and classification of the latest message into predefined scenarios, with confidence.
- Standard actions per scenario plus AI-suggested actions (vendor email, Teams notification, PO status/date updates) with bilingual messages and quoted evidence.
- Code guardrails that discard actions for auto-replies and irrelevant mail.
- SQL views that prioritize a daily worklist; an analyst reviews and executes each action.
- Full audit of suggested versus manual actions, real-time notifications and per-call token/cost tracking.

## Impact achieved

Analysts no longer have to read long vendor email threads from scratch every day: they start from a prioritized worklist with summaries and suggested actions, execute them in one place and keep every decision audited.
