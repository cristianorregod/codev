## My role

The project was my initiative, and I'm still its direct owner. In a two-person team, I was responsible for its architecture, agents and API from the first MVP to the current feature work.

- **Agent architecture**: Designed the LangGraph state graph with a supervisor that plans, delegates to specialists and reviews their results before answering.
- **Specialised agents**: Built the credit, real estate, client data and financial analysis (Brujula) agents, each with its own tools and instructions.
- **API and security**: Developed the FastAPI service with JWT authentication, per-user chat ownership and response streaming.
- **Document pipeline**: Implemented direct PDF uploads to Azure Blob Storage, AI extraction of credit reports and PDF report generation.
- **Data and delivery**: Set up PostgreSQL persistence, versioned SQL migrations, the Docker image and the technical documentation.

## Key project features

- Supervisor agent that builds an ordered plan of specialists, reviews each result and decides whether to continue or finalize, with an iteration limit to prevent loops.
- Credit agent that answers policy and requirement questions using retrieval over a document vector store.
- Real estate agent that searches properties through an external listings API with filters such as city, budget and property type.
- Client data agent that queries the company backend for the client linked to the chat, requesting only the level of detail the question needs.
- Brujula agent that analyzes an uploaded credit bureau report, grounds its interpretation in a reference manual and generates a structured financial analysis PDF.
- A final responder node that keeps a single, consistent voice in every answer.
- Per-chat conversation memory in PostgreSQL, synchronous and streaming (SSE) endpoints, and identity checks that keep each chat tied to one client.

## Impact achieved

Consultants get one conversational entry point for operations and credit questions. The assistant also analyzes credit bureau reports and generates a client-ready financial report, which doubled the sales advisors’ client management capacity.

## Technologies

| Technology          | Use / Implementation                                                 |
| ------------------- | -------------------------------------------------------------------- |
| Python              | Main language for the agents, API and document pipeline.             |
| LangGraph           | State graph that orchestrates the supervisor and specialised agents. |
| LangChain           | Model integration, tool binding and structured outputs.              |
| OpenAI              | LLMs for every agent, file search retrieval and PDF analysis.        |
| FastAPI             | HTTP API with JWT authentication, chat endpoints and SSE streaming.  |
| PostgreSQL          | Conversation checkpointer, chat ownership, documents and reports.    |
| Azure Blob Storage  | Storage of uploaded credit reports and generated PDF documents.      |
| Jinja2 / WeasyPrint | HTML report templates rendered to PDF.                               |
| Docker              | Container image with the native dependencies for PDF rendering.      |
