## Languages and backend

- Python: 4 years, advanced level. I've used it on the Vendor sourcing recommendation engine, the IDRA MCP Server, the Colraices Multi-Agent AI Assistant and the AI worker of the RFQ AI vendor response automation. On several of them I built the API with FastAPI.
- TypeScript / Node.js: 4 years, advanced level. It's the foundation of the Sales order approval AI agent, the Walle logistics AI agent and the Salesforce ⇄ NetSuite integration platform.
- Laravel / PHP: 5 years, intermediate level.

## Frontend

- React / Next.js: 5 years, advanced level. For example, I built most of the review screens of the sales order approval agent and the review interface of the RFQ automation.

## Databases

- PostgreSQL / SQL: 4 years, advanced level. I designed the SQL transformation layer of the sourcing engine, wrote the extraction queries for the NetSuite ERP migration and have given SQL mentoring to the analytics team.

## Enterprise platforms

- NetSuite (SuiteScript): 3 years, intermediate level. I migrated custom scripts and workflows on the NetSuite ERP migration and developed API and SOAP integrations.
- Salesforce: 2 years, intermediate level, mainly on the Salesforce ⇄ NetSuite integration platform.

## Artificial intelligence

- AI agents (LangGraph, MCP, RAG): 2 years, intermediate level. LangGraph on the Colraices Multi-Agent AI Assistant, MCP on the IDRA MCP Server and RAG on the sourcing engine.

## Cloud and DevOps

- Docker, Azure and AWS: 2 years, intermediate level. For example, the IDRA MCP Server and the sourcing engine run on Docker, and the Colraices assistant uses Azure Blob Storage.

## Other tools

Technologies that appear in my stack but are not on this list are tools I have worked with or know, but I don't have a defined level or number of years for them.
